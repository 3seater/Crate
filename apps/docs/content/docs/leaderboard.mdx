The **Leaderboard** ranks traders by performance across the Polymarket ecosystem.

## Columns

| Column | Description |
|--------|-------------|
| **Rank** | Position on the leaderboard, with trader name and address. |
| **Volume** | Total trading volume. |
| **PNL** | Profit and loss for the selected period. |
| **Positions** | Current position value. |
| **Predictions** | Number of markets traded. |
| **Win Rate** | Percentage of winning predictions. |

All columns are sortable.

## Time Periods

Filter the leaderboard by time window:
- **All** — Lifetime performance (default).
- **Today** — Last 24 hours.
- **Weekly** — Last 7 days.
- **Monthly** — Last 30 days.

## Trader Actions

Click any trader row to open their profile. From there you can:
- View their positions and trade history.
- **Track** their wallet in the [Address Tracker](/tracker) to follow their trades in real time.

<Callout type="info">
> Leaderboard data updates as markets resolve and trades settle on-chain.
</Callout>
