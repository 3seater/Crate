Doji's charts provide a visual history of market sentiment and probability over time, powered by KLineChart.

## Timeframes

Seven intervals are available in the chart toolbar:

| Interval | Description |
|----------|-------------|
| **1m** | 1-minute candles |
| **15m** | 15-minute candles |
| **1h** | 1-hour candles |
| **D** | Daily candles |
| **W** | Weekly candles |
| **M** | Monthly candles |
| **All** | Full price history |

## OHLC Data

Hover over any candle to see the **Open**, **High**, **Low**, and **Close** prices for that period.

## Chart Types

Use the chart type picker in the top toolbar to switch between visualization styles:

- **Line** — Simple line chart connecting close prices.
- **Candles** — Standard candlestick chart.
- **Hollow Candles** — Hollow candlestick variant.
- **OHLC** — Open-High-Low-Close bar chart.

## Drawing Tools

The left sidebar provides a full set of drawing tools organized by category:

- **Lines** — Horizontal/vertical lines, rays, segments, trend lines, arrows, price lines.
- **Channels** — Price channels, parallel lines.
- **Shapes** — Circle, rectangle, parallelogram, triangle.
- **Fibonacci** — Retracement, segment, circle, spiral, speed resistance fan, extension, Gann box.
- **Waves** — XABCD, ABCD, three/five/eight wave patterns, any waves.

## Additional Controls

- **Screenshot** — Capture the current chart view.
- **Fullscreen** — Expand the chart to fill the screen.
